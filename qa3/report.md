## 3. Реально видимые обрезания / перекрытия

- **320×568 — перекрытие.** Блок «trust» в hero (строка `★★★★★ 5.0 · 37 ОЦЕНОК В 2ГИС` и `ЕЖЕДНЕВНО 09:00 — 19:00`) занимает по вертикали 521.73 → 583.28 px. Фиксированная нижняя панель начинается на 500.48 px, то есть блок целиком уходит под панель; нижняя часть (583.28 > 568) дополнительно ниже границы экрана. На первом экране видны только eyebrow, H1, подзаголовок и две кнопки — блок с рейтингом и часами работы не виден (см. `qa3/mobile-320-hero.png`).
- **360×640.** Лишние 4.02 px приходятся на нижний внутренний отступ hero (`padding-bottom: 92px`), текст ниже границы экрана не уходит: trust-блок заканчивается на ~552 px, панель начинается на 572.48 px — перекрытия нет.
- **375×812, 390×844, 430×932, 768×1024, 1440×900.** Обрезки и перекрытия текста не наблюдаются: trust-блок и нижняя строка (ГОРОД / ПРОДУКЦИЯ / АДРЕС / ЗАПИСЬ, «ЛИСТАЙТЕ») полностью в пределах экрана (см. `qa3/desktop-1440-hero.png`, `qa3/mobile-390-hero.png`).

## 4. Разложение высоты hero на 320×568 (факт)

`section#top` — `flex min-h-[100svh] overflow-hidden`, `min-height` = 568 px (= `100svh`).
Фактическая высота 675.28 px складывается из:

| Составляющая | Значение |
|---|---|
| `padding-top` контейнера `.hero-body` = `calc(var(--header-h) + 1.25rem)` | 96.00 px |
| Контентный блок `.max-w-3xl` (eyebrow 36.78 + H1 75.98 + подзаголовок 97.56 + кнопки 107.41 + trust-блок 61.55 + отступы) | 487.28 px |
| `padding-bottom` `.hero-body` = `calc(68px + 1.5rem)` | 92.00 px |
| **Итого** | **675.28 px** |

Доступная высота при `min-height: 100svh` = 568 px, то есть контент на 107.28 px выше доступного места; `min-height` не является ограничивающим — высоту задаёт контент.
