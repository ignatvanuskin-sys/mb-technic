# MB TECHNIC — сайт премиального сервиса Mercedes-Benz в Астане

Рабочий сайт с онлайн-записью и панелью заявок для сервиса **MB TECHNIC**
(улица Аркайым, 7, Астана). Все данные о компании взяты из реальных источников —
2ГИС и Instagram. Ничего не выдумано: см. [CONTENT-SOURCES.md](CONTENT-SOURCES.md).

---

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:3000
```

Продакшн:

```bash
npm run build
npm start          # http://localhost:3000
```

Проверки (все проходят на текущем состоянии):

```bash
npx tsc --noEmit                    # типы — без ошибок
npm run lint                        # ESLint — без предупреждений
npm run build                       # production-сборка
node scripts/smoke-test.mjs         # 72 сквозных проверки (нужен запущенный сайт)
```

- `/` — лендинг: hero → специализация → услуги → точность → почему мы → процесс →
  отзывы → работы → Instagram → FAQ → контакты с картой.

## Онлайн-запись

Пять шагов, как в брифе: **услуга → автомобиль → дата → время → контакты** →
экран подтверждения с номером заявки (формат `MB-2609-001`).

- Заявка реально сохраняется: `POST /api/bookings` → `data/bookings.json`.
- Валидация дублируется на клиенте и на сервере (`lib/validation.ts`).
- Телефон нормализуется в `+7XXXXXXXXXX`; VIN проверяется по маске (11–17 знаков,
  без I/O/Q); прошедшие даты и «чужие» слоты отклоняются.
- Honeypot-поле отсекает ботов, отвечая им `200 OK` без записи в базу.
- Если запись не удалась, пользователь видит понятную ошибку с телефоном сервиса.

**Проверено:** 63 → 72 автоматических проверки, включая валидацию, honeypot,
переходы статусов, 401 на закрытых эндпоинтах и очистку тестовых данных.

## Панель заявок (`/admin`)

Вход по паролю из переменной окружения `ADMIN_PASSWORD`; сессия — httpOnly-cookie
на 12 часов. Пока переменная не задана, используется демо-пароль `mb-technic`,
и на экране входа висит предупреждение — **перед публикацией задайте свой пароль**.

Что умеет: счётчики (новые заявки / сегодня / на неделю / всего), фильтры по
статусу, поиск по имени, телефону и модели, таблица (на мобильных — карточки),
карточка заявки со всеми полями и кнопками **Подтвердить · В работу · Завершить ·
Отменить · Удалить**, звонок и WhatsApp в один тап, автообновление раз в 45 секунд.

Статусы: `NEW → CONFIRMED → IN_PROGRESS → COMPLETED` (или `CANCELLED`).

Демо-записи создаются кнопкой «Демо-данные» и всегда помечены значком **ДЕМО**,
чтобы их нельзя было спутать с реальными заявками; кнопка «Удалить демо-данные»
стирает только их.

## Дизайн

Тёмная премиальная автомобильная система: глубокий чёрный `#06070A`, graphite,
silver, chrome и один сдержанный электрик-синий `#2F62FF` — отсылка к неоновой
вывеске сервиса. Крупная editorial-типографика (Inter Tight, self-hosted —
латиница + кириллица), моноширинные технические подписи и цифры (JetBrains Mono).

Hero — не «заголовок + три карточки»: слева крупный заголовок, справа полноэкранная
фотография Mercedes-Benz из цеха сервиса с лёгким параллаксом, снизу — строка
технических характеристик, как в спецификации.

Услуги — editorial-список `01…08` с залипающей панелью предпросмотра: при наведении
на строку меняется фотография и подпись. Галерея — masonry-сетка с фильтрами и
лайтбоксом (стрелки, Esc, клик по фону).

Фотографии — реальные снимки сервиса (2ГИС + Instagram): кропнуты от водяного знака,
пережаты до 1400 px и отдаются через `next/image` (AVIF/WebP, lazy-loading, приоритет
только у hero-изображения).

## Проверено (QA)

Автоматика: `npx tsc --noEmit`, `npm run lint`, `npm run build`, 72 сквозных
проверки — без ошибок.

Визуальная проверка в браузере на **320 · 360 · 375 · 390 · 430 · 768 · 1440** px
(отчёты и скриншоты — в `qa/`, `qa2/`, `qa3/`, `qa4/`):

- hero укладывается в первый экран на всех ширинах (разница 0 px),
- горизонтальной прокрутки нет ни на одной ширине (проверка `scrollWidth`),
- мобильная фиксированная панель CTA не перекрывает контент и футер,
- лайтбокс закрывается по Esc, по крестику и по клику на фон,
- залипающая панель предпросмотра услуг меняет изображение при наведении,
- календарь блокирует прошедшие даты, 5 шагов записи проходят до экрана
  подтверждения, заявка появляется в `/admin`,
- карта OpenStreetMap рисует плитки и маркер,
- консоль браузера чистая на `/` и `/admin`.

Найденные в ходе проверки ошибки исправлены, в том числе:

1. **Часовой пояс.** Валидация даты сравнивала её с `toISOString()` и отклоняла
   любую корректную дату в зонах восточнее UTC (Астана, Екатеринбург).
2. **Горизонтальная прокрутка на 320 px** из-за длинных слов в строках услуг.
3. **Hero не влезал в экран** на коротких и очень узких экранах.
4. **Панель CTA перекрывала последние строки футера** на мобильных.
5. **Лайтбокс не закрывался кликом по фону.**
6. **`/admin` был открыт без пароля**, хотя показывает персональные данные клиентов.
7. Подсветка активного пункта меню могла указывать не на тот раздел.

## Ограничения — что нужно решить перед публикацией

| Вопрос | Что сделать |
|---|---|
| **Пароль панели** | Задать `ADMIN_PASSWORD` (сейчас демо-пароль `mb-technic`). |
| **Домен** | Задать `NEXT_PUBLIC_SITE_URL` — используется в canonical, OG, sitemap, robots. Домен не подтверждён источником, по умолчанию стоит заглушка. |
| **Индексация `/admin`** | Уже закрыта `robots.txt` и `noindex`, плюс пароль. |
| **База данных** | Заявки пишутся в файл `data/bookings.json` на сервере приложения. На хостинге с эфемерной файловой системой (serverless) замените `lib/bookings.ts` на реальную БД — остальной код не меняется. |
| **Уведомления** | Сейчас о новой заявке узнают из панели. Если нужно — подключим WhatsApp/Telegram-уведомление администратору. |
| **Права на фото** | Снимки взяты из публичной карточки 2ГИС и Instagram сервиса. Подтвердите у владельца право на публикацию — при необходимости заменяются на оригиналы из его архива. |
| **Заявленные «10+ лет опыта»** | В брифе есть, но источником не подтверждено (карточка 2ГИС создана 01.09.2025, год основания не указан). Поэтому на сайте **не используется**. Включается одной строкой: `lib/site.ts` → `unverifiedClaims.experienceYears.verified = true`. |
