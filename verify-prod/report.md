Замеры сняты с текущей загрузки страницы (viewport 390×844).

**Чего измерить не удалось (честно, без догадок):**
- **Суммарно переданные байты и «5 самых тяжёлых ресурсов» — недостоверны.** Инструмент отдаёт `transferSize = 0` почти по всем записям, т.к. ресурсы в этой сессии брались из кэша (страница перезагружалась многократно). Реально измеренный «нулевой» объём — артефакт кэша, а **отключить кэш и сделать настоящий hard reload в этом окружении не получилось** (нет доступа к CDP Network.setCacheDisabled из доступных инструментов). Поэтому цифры по байтам здесь не приводятся как факт.
- Наиболее крупные по имени ресурсы (без размера, т.к. кэш): `/_next/image?...owner-03.jpg&w=420`, `owner-video-04.jpg`, `d18130d4c6447cc4.css`, JS-чанки `4bd1b696-…`, `255-…`, `main-app-…`.
- **Замечание по сети:** POST на продовый `/api/bookings` в сетевом логе зафиксировать не удалось (в буфере лога пропущен интервал нашей сессии), поэтому HTTP-статус продовой отправки заявки инструментально не подтверждён — подтверждён только результат в UI (дружелюбная ошибка + кнопка WhatsApp).

### Оставшиеся дефекты

1. **КРИТИЧНО (безопасность):** `/admin` в продакшене в демо-режиме и публично показывает дефолтный пароль `mb-technic` вместе с текстом «Задайте переменную окружения ADMIN_PASSWORD». Админка фактически открыта любому. Нужно задать `ADMIN_PASSWORD` в Vercel и убрать демо-подсказку.
2. **UX:** после ошибки отправки блок с сообщением и кнопка «Отправить заявку в WhatsApp» появляются ниже зоны видимости (кнопка WhatsApp: top 818 → bottom 891 при innerHeight 844) — нужен автоскролл к блоку ошибки.
3. **A11y:** блок ошибки не имеет `aria-live`/`role="alert"` — скринридер не озвучит отказ.
4. **A11y:** инлайновая ссылка «2ГИС» в дисклеймере отзывов — 30×15 px (меньше 44×44).
5. **Инфо:** canonical/og:url/sitemap указывают на `mbtechnic.kz`, а не на проверяемый `mb-technic.vercel.app` — ожидаемо для продакшн-домена, но при проверке превью это нужно учитывать.

### Чего не удалось измерить в этом окружении (без догадок)

- суммарные переданные байты и «топ-5 ресурсов по размеру» (кэш не отключается → `transferSize = 0`);
- HTTP-статус POST продовой отправки заявки (пропуск в сетевом логе);
- полноразмерный скриншот всей страницы (инструмент поддерживает только viewport).
