# Верификация мобильных анимаций — https://mb-technic.vercel.app/?v=anim1

## Методика и ограничения
- Встроенный браузер отключён в настройках Accio → использован Chrome пользователя.
- Мобильные размеры заданы через CDP device-metrics override (`browser_act resize`), подтверждено `window.innerWidth = 390`.
  Из-за классического скроллбара ширина вёрстки на 10px меньше: при 390 → 380, при 430 → 420, при 320 → 310.
- **Важно (артефакт окружения):** окно Chrome периодически считается невидимым (`document.visibilityState = 'hidden'`),
  и Chrome «замораживает» часы анимаций: `getAnimations().currentTime` стоит на 0, плавный скролл не выполняется.
  Все замеры ниже сделаны при `visibilityState = 'visible'` (через `browser_focus`) и с
  `window.scrollTo({behavior:'instant'})` — иначе получить корректные значения невозможно.
- `prefers-reduced-motion` **эмулировать не удалось**: ни один доступный инструмент не даёт `Emulation.setEmulatedMedia`.
  Ниже приведено подтверждение из CSSOM, а не результат эмуляции.

## 1. Нижний CTA-бар (только после скролла) — ИСПРАВЛЕНИЕ ПОДТВЕРЖДЕНО
Элемент: `div.fixed.inset-x-0.bottom-0.z-[90] … md:hidden`, текст «ПОЗВОНИТЬ / ЗАПИСАТЬСЯ», высота 67.52px.

| Состояние | scrollY | rect.top | rect.bottom | transform | opacity | inert | pointer-events |
|---|---|---|---|---|---|---|---|
| A — самый верх | 0 | 844 | 911.52 | `matrix(1,0,0,1,0,67.5156)` (= своя высота) | 0 | **есть** | none |
| B — +1 экран | 844 | 776.48 | 844 (= `innerHeight`) | `matrix(1,0,0,1,0,0)` (identity) | 1 | нет | auto |
| C — назад вверх | 0 | 844 | 911.52 | `matrix(1,0,0,1,0,67.5156)` | 0 | **есть** | none |

- A: бар полностью за нижней кромкой (top = `innerHeight`), `aria-hidden=true`, не кликабелен.
  Вместо него виден CTA героя «ЗАПИСАТЬСЯ НА СЕРВИС»: top 541.8, bottom 594.9, opacity 1, `.hero-cta` opacity 1.
- B: бар полностью виден, `aria-hidden=false`, низ бара совпадает с низом вьюпорта (844 = 844).
  CTA героя ушёл за экран (bottom −249.1).
- C: бар скрылся снова, значения совпадают с A (транзишен 0.5s, замер после 950 мс).
- **Порог появления** (20 шагов по 42.2px): при `scrollY ≤ 464` бар скрыт, первый видимый шаг — **`scrollY = 506`**
  (класс меняется + opacity растёт 0.27 → 1 за ~0.5 c). Проверка границы: y=463 — скрыт (opacity 0, translateY 67.5),
  y=506 — виден (opacity 1, identity). Точный порог лежит в диапазоне **(465…506)px**, что соответствует ~500px.
- Клик «ЗАПИСАТЬСЯ» в баре (состояние B) → **модальное окно записи открылось**:
  `div.fixed.inset-0.z-[120]`, `role="dialog"`, `aria-modal="true"`, содержимое
  «MB TECHNIC · ОНЛАЙН-ЗАПИСЬ / ШАГ 1 / 5 · УСЛУГА / ЧТО НУЖНО СДЕЛАТЬ?» + список услуг.
  Закрыто по Escape → модалка удалена из DOM (0 элементов), полей ввода на странице снова 0.

## 2. Кнопка «Записаться» в хедере
`button.btn.btn-primary.hidden.min-[420px]:inline-flex`
- **390×844** (ширина вёрстки 380): `display: none`, rect = 0/0/0/0 → **скрыта** (как ожидается).
- **430×932** (ширина вёрстки 420): `display: flex`, left 223.19, top 16.5, right 344, bottom 58.5, размер **120.81 × 42**, видима → **показана** (как ожидается).
- 320×568 (вёрстка 310): `display: none` → скрыта.

## 3. Анимации на мобильном (390×844)
- **Фото героя:** в покое `transform: matrix(1.08, 0, 0, 1.08, 0, 0)` → **scale = 1.08** (анимация `heroSettle` 1.7s both, opacity 1).
- **Горизонтального переполнения нет:** `documentElement.scrollWidth` 380 ≤ `innerWidth` 390 (сам img выходит за края:
  left −15.2 / right 395.2, но обрезается `#top { overflow: hidden }`).
- **Сдвига макета после анимации загрузки нет:** CLS = **0** (0 записей `layout-shift`), `#top` height 844 = `innerHeight` и до, и после оседания.
- **Список услуг** (`#services`, 10 элементов `.reveal`: 2 заголовка + 8 строк): через ~1.6 c на экране
  `is-in` у **5** элементов = 2 заголовка + строки 01, 02, 03 (opacity 1, transform none).
  Строки 04–08 остались `opacity: 0` / `translateY(26px)`. Строки 04 и 05 при этом были внутри вьюпорта,
  но не помечены — срабатывает отступ/порог IntersectionObserver.
- **Стаггер подтверждён:** `transition-delay` строк = 0s, 0.055s, 0.11s, 0.165s, 0.22s, 0.275s, 0.33s, **0.385s**
  (первая 0s против последней 0.385s, шаг 55 мс; длительность 0.85s).
- **prefers-reduced-motion:** эмуляция недоступна (см. ограничения). В CSS найдено правило и его содержимое:
  `@media (prefers-reduced-motion: reduce) { html{scroll-behavior:auto} *,::after,::before{animation-duration:.001ms!important; animation-iteration-count:1!important; transition-duration:.001ms!important} .js .reveal{opacity:1; transform:none} }`
  → при `reduce` любой ещё не проскролленный `.reveal` уже `opacity: 1` / `transform: none`. **Измерением не подтверждено.**

## 4. Регрессия
- **390×844:** `documentElement.scrollWidth` 380 vs `innerWidth` 390 → переполнения нет. `#top` height 844 = `innerHeight` 844. Высота документа 27902.
- **320×568:** `documentElement.scrollWidth` 310 vs `innerWidth` 320 → переполнения нет. `#top` height 568 = `innerHeight` 568.
  Нюанс: `body.scrollWidth` = 329 (> 310), т.е. контент выходит за вёрстку на ~19px, но полностью обрезается
  `body { overflow-x: hidden }` / `html { overflow-x: clip }` — скролла страницы не появляется.
- **Консоль при загрузке `/`:** захвачено **0 сообщений** console.* (log/warn/error) и **0 JS-исключений** —
  предупреждений о гидратации нет. (Замечание: сообщения читаются тем же подключением, что и замеры; «пусто» = ничего не залогировано.)
- **Бар не перекрывает низ футера (состояние B, самый низ страницы, scrollY 27058):**
  последний абзац футера (дисклеймер «Информация на сайте носит справочный характер…») — низ 752.28 во вьюпорте,
  верх бара — 776.48 → зазор **24.2px, перекрытия нет**. Глубже этого абзаца текста в футере нет
  (абс. низ 27810.3, сам блок футера заканчивается на 27902.3 — это нижний паддинг).

## Итог
Исправление работает: в состоянии A и C бар скрыт (переведён вниз на свою высоту, opacity 0, `inert`, `aria-hidden`),
в состоянии B полностью виден; первое появление — при `scrollY ≈ 500px` (в диапазоне 465–506). Кнопка в хедере
скрыта на 390 и видна на 430. Фото героя в покое scale 1.08, CLS = 0, горизонтального переполнения нет,
ошибок/предупреждений в консоли нет, бар не закрывает последнюю строку футера.
Не измерено: реальная эмуляция `prefers-reduced-motion` (инструментарий недоступен) — приведено CSS-подтверждение.
